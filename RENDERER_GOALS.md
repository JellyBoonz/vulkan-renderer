# Vulkan Renderer Goals

We will work from the highest useful level first, adding detail only when we begin each goal.

- [ ] 1. Set up a window
  - Create an application window that stays open and handles close events.

- [ ] 2. Set up Vulkan
  - Connect Vulkan to the window and establish the GPU, presentation, and rendering foundation.

- [ ] 3. Draw a triangle
  - Render and present one triangle, initially with the smallest practical amount of geometry and asset handling.

After the triangle works, connect the existing glTF parsing work to GPU vertex buffers.
